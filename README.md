# Bolão Futebol Diego Dias

Protótipo inicial responsivo para bolão de palpites de futebol.

## O que já existe
- Interface adaptada para celular e computador.
- Nome do participante e palpites guardados localmente no navegador.
- Jogos de demonstração e formulário para adicionar jogos.
- Área visual de ranking e regras iniciais de pontuação.

## Limitações importantes
Esta primeira versão é apenas um protótipo local. Os dados ficam no navegador do aparelho e não são compartilhados entre participantes. A área administrativa não possui autenticação segura. Login real, banco de dados Firebase, validação de resultados, ranking compartilhado e pagamentos Pix precisam ser configurados antes de usar publicamente.

## Publicar no GitHub Pages
1. Abra Settings do repositório.
2. Entre em Pages.
3. Em Build and deployment, escolha Deploy from a branch.
4. Selecione a branch main e a pasta /(root), depois salve.
5. Aguarde a publicação indicada pelo GitHub Pages.
